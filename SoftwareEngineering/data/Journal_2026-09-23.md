I learned that [TypeORM](https://typeorm.io/) is no longer the cool kid on the
block.  [Prisma](https://www.prisma.io/) and
[Drizzle](https://orm.drizzle.team/) are the new things for
[TypeScript ORMs](https://navanathjadhav.medium.com/prisma-vs-drizzle-vs-typeorm-the-modern-orm-battle-618694d6361c).
Personally, I like an ORM that keeps me out of SQL and into the host language,
e.g., Active Record in Ruby.  It has an escape hatch for the rare occasions when
I need to write bespoke SQL.  I appreciate the close correspondence between what
I can write in Drizzle and the resulting SQL.  I find the SQL keywords in camel
case odd, though, and would take some getting used to.
